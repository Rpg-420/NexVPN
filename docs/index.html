Three Engines. One App.

NexVPN doesn't lock you into a single protocol. It dynamically dispatches your connection to the most powerful engines available in the censorship evasion landscape.

  • Aether Core (MASQUE)

    HTTP/3 over UDP tunneling with adaptive IP scanners (Turbo to Ironclad) for hunting clean Cloudflare endpoints (gool/warp-in-warp).

  • Sing-box Core

    The industry standard for VLESS Reality, Trojan, Hysteria2, and high-performance WireGuard. Features full-system TUN and Smart DNS.

  • OpenVPN Core

    Native Layer-3 routing for classic configurations, perfectly integrated with the cross-platform Kill Switch firewall chains.
