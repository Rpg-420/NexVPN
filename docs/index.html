ربات استخراج پروکسی تلگرام Telegram Proxy Scraper

دریافت و استخراج خودکار صدها پروکسی MTProto و V2Ray از کانال‌های معتبر تلگرامی همراه با تست پینگ موازی و اجرای مستقیم با ۱ کلیک در تلگرام دسکتاپ. Automated real-time crawler scraping verified public Telegram channels for MTProto & V2Ray nodes with live concurrent ping tests.

اسکنر IP تمیز کلودفلر Cloudflare Clean IP Scanner

اسکن همزمان صدها رنج IPv4 کلودفلر، سنجش دقیق جیتر، تاخیر و پکت‌لاس برای یافتن سریع‌ترین آی‌پی‌های بدون فیلتر جهت استفاده در کانفیگ‌های WARP و CDN. Multi-threaded CIDR scanner testing latency, jitter, and packet loss across WARP and CDN IPv4 subnets to assign clean endpoints.

استودیوی فرگمنت TLS TLS Fragment Studio

تکه‌تکه کردن پکت‌های ClientHello با تنظیم فواصل تاخیر و طول بایت‌ها برای شکستن شناسایی SNI و عبور تضمینی از سامانه‌های DPI اپراتورها. Visual studio for ClientHello packet fragmentation with custom delay intervals to bypass SNI-based deep packet inspection.

بهینه‌ساز هوشمند اپراتورها Smart ISP Optimizer

تشخیص خودکار اپراتور شما (همراه اول، ایرانسل، شاتل، مخابرات و...) و اعمال تنظیمات فرگمنت، رنج IP تمیز و MTU بهینه مختص همان اپراتور. Auto-detects active ISP (MCI, Irancell, Shatel, Mokhaberat) and configures tailor-made fragmentation, clean IP pools, and MTU.

کیل‌سوئیچ لایه صفر سیستمی Zero-Leak System Kill Switch

مدیریت مستقیم دیواره آتش سیستم‌عامل (Windows Netsh، Linux iptables، macOS pfctl) جهت مسدودسازی کامل هرگونه نشت تصادفی IP هنگام قطعی تونل. Kernel-level firewall lockdown (Netsh, iptables, pfctl) preventing any unprotected outbound traffic if the VPN connection drops.

سپر ضد نشت DNS Multi-Resolver DNS Shield

تست مداوم نشت DNS در برابر سرورهای کلودفلر، گوگل و Quad9 و جلوگیری کامل از حملات مسمومیت DNS (DNS Hijacking) از طریق DoH رمزنگاری‌شده. Probes and enforces DNS queries through encrypted DoH/DoT resolvers (Cloudflare, Quad9, Google) to defeat DNS poisoning.

تفکیک ترافیک برنامه‌ها Process-Based Split Tunneling

انتخاب آسان برنامه‌های اجرایی (مانند برنامه‌های بانکی یا بازی‌های آنلاین) جهت عبور مستقیم از اینترنت بدون فیلترشکن یا عبور اجباری از VPN. Intercept traffic at the executable process level to bypass banking apps or route specific tools directly through the tunnel.

کنترل از راه دور با موبایل Mobile Remote Web Companion

اسکن بارکد QR با گوشی روی همان شبکه Wi-Fi و وارد کردن پین امنیتی ۶ رقمی برای قطع/وصل و مانیتورینگ سرعت سیستم از روی گوشی بدون نیاز به دست زدن به کیبورد. Control your desktop VPN from any phone on Wi-Fi via a secure PIN-authenticated QR web companion without touching your PC.

اشتراک پروکسی در شبکه محلی LAN Proxy Sharing

اشتراک اتصال امن فیلترشکن با تلویزیون هوشمند (Smart TV)، کنسول‌های بازی (PS5/Xbox) و سایر دستگاه‌های شبکه خانگی بدون نیاز به نصب برنامه روی آنها. Share encrypted VPN tunnel access over local Wi-Fi with Smart TVs, gaming consoles, and mobile devices via local HTTP/SOCKS5.

پزشک هوشمند شبکه Smart Network Doctor

تعمیر اورژانسی و خودکار شبکه در ۱ ثانیه (خالی کردن کش DNS، ریست استک Winsock، پاکسازی پروکسی‌های رهاشده و بستن هسته‌های گیر کرده). One-click emergency repair to purge DNS caches, reset Winsock/Netlink stacks, clear zombie proxies, and kill dangling processes.

حالت گیمینگ و ویجت شناور Gaming Mode & Floating HUD

شتاب‌دهنده پکت‌های UDP با جیتر فوق‌العاده پایین برای بازی‌های آنلاین رقابتی همراه با ویجت مینیاتوری همیشه در دسترس روی صفحه دسکتاپ. Ultra low-jitter UDP optimization for online gaming paired with a semi-transparent floating desktop widget showing live speed and latency.

والت رمزگذاری‌شده و ارسال محلی Encrypted Vault & P2P Sync

پشتیبان‌گیری رمزگذاری‌شده با الگوریتم AES-256، همگام‌سازی با GitHub Gist و انتقال بی‌سیم نودها میان لپ‌تاپ‌های اطراف در همان شبکه محلی. AES-256 encrypted vault backup, GitHub Gist cloud synchronization, and peer-to-peer Wi-Fi profile sharing between local devices.

                            اگر پس از قطع فیلترشکن، اینترنت ویندوز یا مرورگرها قطع شد چه کنیم؟
                            What should I do if internet disconnects after turning off the VPN?
                        

                        
                    

                    

                        کافیست در نوار ابزار سایدبار برنامه روی دکمه Network Doctor (پزشک هوشمند شبکه) کلیک کنید. این ابزار به صورت خودکار کش DNS را خالی کرده، استک Winsock و تنظیمات پروکسی گیرکرده در رجیستری ویندوز را پاکسازی می‌کند و اینترنت بلافاصله وصل می‌شود.
                    

                


                
                

                    

                        

                            
                            چگونه در اپراتور همراه اول یا ایرانسل قطعی‌های فیلترینگ SNI را برطرف کنیم؟
                            How to bypass SNI throttling on mobile networks (MCI / Irancell)?
                        

                        
                    

                    

                        وارد بخش Fragment Studio در نرم‌افزار شوید و گزینه فرگمنت را با سایز 10-30 و تاخیر 15-30ms فعال کنید. همچنین می‌توانید از پروتکل Aether MASQUE (HTTP/3) که ترافیک را در قالب پکت‌های استاندارد وب مخفی می‌کند استفاده نمایید.
                    

                


                
                

                    

                        

                            
                            چرا در لینوکس حتماً باید اسکریپت install_linux.sh را اجرا کنیم؟
                            Why do I need to run install_linux.sh on Linux?
                        

                        
                    

                    

                        این اسکریپت دسترسی سیستمی cap_net_admin و سیاست‌های سرویس Polkit را تنظیم می‌کند. در صورت عدم اجرای آن، لینوکس در هر بار اتصال، تغییر روتینگ یا ایجاد آداپتور TUN از شما پسورد روت (Sudo) درخواست خواهد کرد. با یک بار اجرای آن، برنامه کاملاً سایلنت و بدون پسورد اجرا می‌شود.
                    

                


                
                

                    

                        

                            
                            تفاوت حالت TUN Mode و System Proxy چیست؟
                            What is the difference between TUN Mode and System Proxy?
                        

                        
                    

                    

                        در حالت TUN Mode، یک کارت شبکه مجازی ساخته شده و ۱۰۰٪ ترافیک کل سیستم (بازی‌ها، مرورگرها، دانلود منیجر، ترمینال و برنامه‌ها) از تونل عبور داده می‌شود. در حالت System Proxy فقط برنامه‌هایی که از پروکسی سیستم‌عامل پیروی می‌کنند (مانند مرورگرها) از فیلترشکن رد می‌شوند.
