# NexVPN Pro

![NexVPN Pro Banner](https://raw.githubusercontent.com/NexVPN/NexVPN/main/build/appicon.png)

**NexVPN Pro** یک کلاینت و موتور دور زدن فیلترینگ و VPN چندپروتکله، کراس‌پلتفرم و نسل جدید است که برای حداکثر پایداری در برابر حملات Deep Packet Inspection (DPI) و محدودیت‌های شدید شبکه طراحی شده است. NexVPN با استفاده از فریم‌ورک Wails، ری‌اکت (React) و زبان Go، پیشرفته‌ترین هسته‌های مسیریابی و مبهم‌سازی ترافیک در جهان را در یک رابط کاربری یکپارچه و هوشمند ارائه می‌دهد.

---

## 🌟 ویژگی‌های کلیدی

### 🧠 موتور هوشمند چند-هسته‌ای (Multi-Core)
برنامه NexVPN به یک پروتکل یا هسته محدود نیست! این برنامه به طور هوشمند ترافیک شما را به بهترین هسته ممکن هدایت می‌کند:
- **هسته Aether**: موتور پرچمدار و پیشرفته برای دور زدن شدیدترین نوع فیلترینگ. پشتیبانی از **MASQUE** (پروتکل HTTP/3 بر بستر UDP/TCP) و **gool** (تکنیک Cloudflare WARP-in-WARP). مجهز به اسکنر قدرتمند پنج‌حالته (Turbo, Balanced, Thorough, Stealth, Ironclad) برای یافتن IPهای تمیز به صورت لحظه‌ای.
- **هسته Sing-box**: معروف‌ترین و قدرتمندترین موتور برای پروتکل‌های Xray/V2Ray (مانند VLESS، Trojan، Hysteria2) و همچنین تونل‌زنی فوق‌سریع WireGuard. پشتیبانی از مسیریابی پیشرفته، Reality و حالت تونل کل سیستم (Full-System TUN).
- **هسته OpenVPN**: مسیریابی لایه ۳ نیتیو با یکپارچگی کامل با آداپتورهای TAP/Wintun.

### 🛡️ یکپارچگی کراس‌پلتفرم با سیستم‌عامل
نرم‌افزار NexVPN به صورت کاملاً نیتیو با سیستم‌عامل شما تعامل می‌کند:
- **ویندوز**: یکپارچگی عمیق با Wintun، مدیریت پروکسی از طریق رجیستری و اسپلیت-تونلینگ بر اساس پروسس (Process-based Split Tunneling).
- **لینوکس**: اجرای بدون پسورد هسته‌ها از طریق **Polkit** (پشتیبانی از `pkexec` و `CAP_NET_ADMIN`)، رفرش اتوماتیک پروکسی در دسکتاپ‌های KDE/GNOME و مسیریابی نیتیو `netlink`.
- **مک (macOS)**: پیکربندی لیست استثنائات پروکسی (Bypass)، اعمال کیل‌سوئیچ در لایه‌های `pfctl` و هماهنگی کامل با LaunchAgent برای اجرای خودکار هنگام استارت‌آپ.

### 🩺 پزشک هوشمند شبکه و سیستم تعمیر
آیا شبکه شما مختل شده است؟ «پزشک شبکه» (Network Doctor) به صورت کراس‌پلتفرم می‌تواند مشکلات را تشخیص داده و سیستم شما را به طور خودکار تعمیر کند. این سیستم آداپتورهای گیرکرده را ریست می‌کند، کش DNS را پاک می‌کند (از طریق `ipconfig`، `resolvectl` یا `dscacheutil`)، پروکسی‌های رهاشده را تمیز کرده و پروسس‌های مخفی هسته‌ها را می‌بندد.

### 🎯 تفکیک ترافیک برنامه‌ها (Split Tunneling)
شما می‌توانید مشخص کنید دقیقاً چه برنامه‌هایی از VPN عبور کنند. سیستم Split Tunneling در NexVPN ترافیک را بر اساس فایل اجرایی پروسس (Executable) شناسایی و هدایت می‌کند که به شما اجازه می‌دهد اپلیکیشن‌های داخلی را از VPN مستثنی کنید.

### 🔒 کیل‌سوئیچ بومی (Native Kill Switch)
جلوگیری از نشت اطلاعات! NexVPN با دستکاری مستقیم فایروال سیستم‌عامل شما (`netsh` در ویندوز، زنجیره‌های `iptables` در لینوکس و `pfctl` در مک) تضمین می‌کند که اگر اتصال VPN به صورت ناگهانی قطع شود، هیچ ترافیکی به اینترنت نشت نکند.

## 🚀 راهنمای شروع سریع

### پیش‌نیازها
- [Go 1.21+](https://golang.org/doc/install)
- [Node.js 18+](https://nodejs.org/en/download/)
- [Wails CLI](https://wails.io/docs/gettingstarted/installation)

### نصب و بیلد

۱. **کلون کردن مخزن:**
   ```bash
   git clone https://github.com/NexVPN/NexVPN.git
   cd NexVPN
   ```

۲. **پیکربندی پیش‌نیازها در لینوکس (فقط لینوکس):**
   برای اجرای بدون پسورد هسته‌ها و پشتیبانی کامل از حالت TUN، سیاست‌های Polkit را نصب کنید:
   ```bash
   sudo ./install_linux.sh
   ```

۳. **حالت توسعه (Development Mode):**
   اجرای برنامه با قابلیت بارگذاری زنده (Hot-reload) برای توسعه‌دهندگان:
   ```bash
   wails dev
   ```

۴. **بیلد نسخه نهایی (Production Build):**
   کامپایل و ساخت فایل اجرایی نهایی برای سیستم‌عامل شما:
   ```bash
   wails build
   ```

## 🛠️ معماری پروژه

پروژه NexVPN بر اساس یک معماری ماژولار بنا شده است:
- **فرانت‌اند (`/frontend`)**: رابط کاربری زیبا و واکنش‌گرا که با React، TypeScript و Tailwind CSS ساخته شده است.
- **بک‌اند (`/internal`)**: کنترلرهای زبان Go که مدیریت پروکسی سیستم (`sysproxy`)، آداپتورهای پروتکل‌ها (`protocols`)، دانلود و نصب خودکار هسته‌ها (`core`) و تعمیرات سیستم (`parser/doctor`) را بر عهده دارند.
- **هسته‌ها (`/bin`)**: فایل‌های اجرایی موتورها (مانند `sing-box`, `aether`, `openvpn`) که در زمان بیلد در برنامه جاسازی شده یا به طور خودکار از سرور دانلود می‌شوند.
