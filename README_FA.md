## 🌟 معرفی نکس‌وی‌پی‌ان

**نکس‌وی‌پی‌ان پرو (NexVPN Pro)** یک کلاینت متن‌باز، فوق‌العاده سریع و مدرن برای سیستم‌عامل ویندوز است. با تلفیق ۳ هسته استاندارد جهانی (**Sing-Box**، **Xray-Core** و **Native OpenVPN**) و استفاده از درایور کرنل کارت شبکه مجازی **Wintun**، نکس‌وی‌پی‌ان بالاترین سطح سرعت، پایداری و عبور از فیلترینگ هوشمند (DPI) را حتی در شرایط شدید اختلال شبکه فراهم می‌کند.

## ✨ ویژگی‌های کلیدی

| قابلیت | توضیحات |
| :--- | :--- |
| 🚀 **پشتیبانی جامع از پروتکل‌ها** | سازگاری کامل با `VLESS Reality`، `VLESS Vision`، `VMess`، `Trojan`، `Shadowsocks`، `Hysteria 2`، `TUIC`، `WireGuard`، `Cloudflare WARP`، `AmneziaWG` و `OpenVPN`. |
| 🛡️ **مسیریابی دوگانه (Dual-Routing)** | ترکیب همزمان کارت شبکه مجازی **Wintun TUN** با پروکسی سیستمی برای اطمینان از عبور ۱۰۰٪ ترافیک تمامی نرم‌افزارها و بازی‌ها. |
| ⚡ **مبهم‌سازی پیشرفته AmneziaWG** | ارسال بسته‌های فریبنده تصادفی (`Jc/Jmin/Jmax`) و هدرهای جادویی (`H1-H4`) جهت باز کردن وارپ روی تمامی رنج‌های ابری کلودفلر. |
| 🔭 **مرکز کاوش (Discovery Hub)** | اسکن، تست سلامت و فیلتر لحظه‌ای صدها کانفیگ رایگان، پروکسی‌های تلگرام و تارگت‌های کلودفلر با پرچم کشورها. |
| 🔬 **استودیوی فرگمنت ضد DPI** | خرد کردن بسته‌های هندشیک TLS به پکت‌های بسیار ریز برای دور زدن فیلترینگ SNI و فایروال‌های هوشمند اپراتورها. |
| 🎯 **اسکنر آی‌پی تمیز Anycast** | اسکنر چندنخی جهت کشف آی‌پی‌های بدون پکت‌لاس کلودفلر و تولید خودکار اکانت وارپ و AmneziaWG بهینه‌شده. |
| 🎮 **حالت گیمینگ و ضد تحریم** | بهینه‌سازی MTU روی 1400، اولویت‌بندی پکت‌های صوتی دیسکورد و بازی‌ها و مجهز به DNSهای ضد تحریم ایرانی و خارجی. |
| 🔗 **زنجیره چندهاپ (Proxy Chaining)** | هدایت متوالی ترافیک از ۲ تا ۴ سرور به صورت تودرتو برای دستیابی به نهایت امنیت، ناشناسی و پایداری. |
| 📡 **اشتراک‌گذاری Wi-Fi در شبکه** | تبدیل کامپیوتر به درگاه پروکسی برای استفاده گوشی، تلویزیون هوشمند، کنسول‌های PS/Xbox از اینترنت آزاد. |
| 📱 **مرکز کنترل ریموت موبایل** | اسکن بارکد QR با گوشی و قطع/وصل و مدیریت برنامه از طریق مرورگر موبایل بدون نیاز به نصب هیچ اپ اضافی. |
| 🩺 **پزشک هوشمند شبکه** | عیب‌یابی و تعمیر ۱-کلیکه شبکه، پاکسازی کش DNS، ریست Winsock و رفع خطاهای اتصال سرورها. |
| 📊 **مانیتورینگ زنده و سهمیه حجم** | نمایش دقیق سرعت لحظه‌ای، گراف داینامیک مصرف ترافیک و تعریف سهمیه مصرف ماهانه. |
| 🌐 **رابط کاربری مدرن دوزبانه** | تم تاریک سایبرپانک با پشتیبانی کامل از زبان فارسی (راست‌چین با فونت وزیرمتن) و انگلیسی. |

## 💻 نیازمندی‌های سیستمی

- **سیستم‌عامل:** ویندوز ۱۰ (نسخه ۶۴ بیتی) یا ویندوز ۱۱
- **معماری پردازنده:** x86_64 (amd64)
- **دسترسی:** نیاز به اجرای Run as Administrator جهت استقرار کارت شبکه Wintun.
- **رم و حافظه:** حداقل ۲۵۰ مگابایت رم و ۱۰۰ مگابایت فضای خالی.

## 🚀 راهنمای نصب و اجرا

### روش ۱: دریافت نسخه پرتابل (پیشنهادی)

1. فایل زیپ `NexVPN-v1.3.3-Portable-x64.zip` را از بخش [GitHub Releases](https://github.com/Rpg-420/NexVPN/releases) دانلود کنید.
2. آن را در پوشه دلخواه (مثلاً `C:\NexVPN`) اکسترکت کنید.
3. فایل `NexVPN.exe` را به عنوان Administrator اجرا کنید.

### روش ۲: بیلد از سورس کد

#### پیش‌نیازها:
* نصب [Go 1.22+](https://go.dev/dl/)
* نصب [Node.js 18+](https://nodejs.org/)
* نصب [Wails CLI v2](https://wails.io/): `go install github.com/wailsapp/wails/v2/cmd/wails@latest`

```powershell
# کلون ریپازیتوری
git clone https://github.com/Rpg-420/NexVPN.git
cd NexVPN

# نصب وابستگی‌های رابط کاربری
cd frontend
npm install
cd ..

# بیلد خودکار و پکیجینگ ریلیز
powershell -ExecutionPolicy Bypass -File .\package.ps1
```

## 📖 راهنمای کاربری و قابلیت‌های اصلی

### ۱. اتصال به سرورهای V2Ray / Xray
- لینک کانفیگ خود (`vless://`, `vmess://`, `trojan://`, `ss://`, `hy2://`) یا لینک اشتراک سابسکریپشن را کپی و دکمه **وارد کردن (Import)** را بزنید.
- با زدن دکمه **تست پینگ همه (⚡)** سریع‌ترین سرور را انتخاب و دکمه پاور مرکزی را بفشارید.

### ۲. ساخت اکانت ۱-کلیکه Cloudflare WARP و AmneziaWG
- به صفحه **وایرگارد و وارپ** بروید.
- با کلیک روی **ساخت اکانت WARP**، کانفیگ با تنظیمات ضد فیلترینگ AmneziaWG ساخته می‌شود و روی تمامی رنج‌ها متصل می‌گردد.

### ۳. اتصال OpenVPN با عیب‌یابی هوشمند
- فایل `.ovpn` را اضافه کرده و در صورت نیاز یوزرنیم/پسورد را وارد کنید.
- سیستم با اعمال بهینه‌سازی MTU 1360 و پنجره رپلی ۵۱۲ پکت از افت کیفیت یا قطعی جلوگیری می‌کند. در صورت اشتباه بودن رمز، پیام خطای شفاف به شما نمایش داده می‌شود.

### ۴. مرکز کاوش (Discovery Hub)
- از تب‌های **VLESS**, **VMESS**, **TROJAN**, **SHADOWSOCKS**, **HYSTERIA2** نودهای رایگان عمومی را فیلتر کرده، تست سلامت بگیرید و به لیست خود اضافه کنید.
